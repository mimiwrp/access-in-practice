# Access in Practice

A guided DEI reflection canvas for staff working with children. Created by Mimi as a resource connecting identity, questions, actions, shared support, and diversity, equity, and inclusion in everyday practice.

## Features

- Reflect on identity, perspective, role, and setting.
- Edit guiding questions and write actions, support needs, and DEI connections.
- Select diversity, equity, and inclusion lenses.
- Add or remove reflection rows.
- Print a completed reflection or a blank worksheet.
- Clear entries to start again.

## Run

Open `index.html` in a modern browser. No installation or build step is required.

Entries are held in the open page only. They are not submitted to a server or stored after a refresh. Print to keep a reflection. Use general descriptions without client identifiers.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. Use the published URL shown by GitHub.
